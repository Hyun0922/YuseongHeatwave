# 유성구 폭염 대비 취약지역 통합지도

## 결과물
- `index.html`: GitHub Pages·로컬 웹서버용 진입 파일
- `yuseong-heatwave-map-share.html`: `build_site.py`가 생성하는 데이터·CSS·JavaScript 내장 단일 파일
- `data/*.geojson`, `data/summary.json`: 공개 필드만 포함한 데이터
- `js/*.js`, `css/style.css`: 기능과 스타일 분리본
- `build_site.py`: 원본 파일 사전 검증, 단독 HTML 생성, 도로온도 링크 재추출, ZIP 생성 코드

## 빌드
- 현재 소스를 보존하며 별도 결과 폴더에 생성하려면 `python build_site.py --output-dir <결과 폴더>`를 사용합니다.
- 원본 파일이 누락된 경우 데이터 파일을 다시 쓰기 전에 빌드를 중단합니다.
- 빌드 폴더와 ZIP에는 `.git`, 캐시, 기존 ZIP과 이전 단일 HTML을 포함하지 않습니다.

## 데이터 공개 원칙
- `Welfare_score_100_final`과 사회경제적 취약계층 세부 점수·인원은 HTML과 GeoJSON에 포함하지 않았습니다.
- 거주 기반 민감도는 최종 종합점수와 공개 가능한 연령별 인구구조 집계값만 제공합니다.
- 연락처, 시설 관리번호, 테이블 ID, 로컬 경로와 과거·중간 산출 필드는 제외했습니다.
- 살수차 도로 링크의 `LINK ID`는 이번 요청에 따라 도로온도 상세정보 식별용으로 공개합니다.

## 로딩 방식
- 첫 실행에서 공개 데이터 전체를 한 번에 불러오며, 완료 후에는 지표·등급·정책·LST 레이어를 바꿀 때 추가 데이터 로딩이 발생하지 않습니다.
- 초기 로딩에 실패하면 오류 원인과 다시 시도 버튼을 표시합니다.
- 별도 `통계·분석` 탭의 교차표·산점도·해석 기준은 `분석개요` 하단으로 통합했습니다.

## 네이버 거리뷰
- 통합지도 격자와 정책지원 후보 상세의 `네이버 거리뷰` 버튼에서 선택 위치 반경 300m 내 파노라마를 표시합니다.
- 네이버 Maps JavaScript API는 거리뷰를 처음 열 때 한 번만 불러오고 이후에는 같은 파노라마 인스턴스를 재사용합니다.
- 거리뷰는 우측 하단 플로팅 창으로 열리며 좌상단 핸들을 드래그하거나 방향키로 크기를 조절할 수 있습니다. 크기를 바꾸면 파노라마 화면도 가변 영역을 즉시 채우며, 얇은 제목 표시줄에 선택 위치명이 함께 표시됩니다.
- `js/config.js`의 `naverMapsClientId`에는 브라우저용 Client ID만 사용하며 Client Secret은 저장소에 넣지 않습니다.
- 네이버 클라우드 Maps 애플리케이션에는 배포 도메인과 로컬 테스트 호스트를 Web 서비스 URL로 등록해야 합니다.
- 정책지원의 무차양 버스정류장은 일반 후보와 구분되는 전용 버스 핀 아이콘과 이름 툴팁으로 표시합니다.
