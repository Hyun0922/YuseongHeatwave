# 유성구 폭염 대비 취약지역 통합지도

`index.html`의 시각적 구조를 참고해 제작한 GitHub Pages 게시용 정적 웹지도와 단독 실행 버전입니다.

## 결과물

- `yuseong-heatwave-map-index.html`: GitHub Pages·로컬 웹서버용
- `yuseong-heatwave-map-share.html`: 데이터·CSS·JavaScript를 내장한 단일 파일
- `data/*.geojson`, `data/summary.json`: 공개 필드만 포함한 데이터
- `js/*.js`, `css/style.css`: 기능과 스타일 분리본
- `build_site.py`: 분리형 파일 검증, 단독 HTML 생성, 도로온도 링크 재추출, ZIP 생성 코드
- `legacy_build_base.py`: 최초 원자료 변환 과정의 기준 코드
- `docs/file_field_mapping.csv`: 사용 파일·필드·결합키 매핑표
- `docs/excluded_files_fields.csv`: 제외 필드와 제외 사유
- `docs/verification_report.md`: 최종 기능·공개안전 점검 결과

## 실행

### 단독 실행

인터넷에 연결된 환경에서 `yuseong-heatwave-map-share.html`을 엽니다. 분석 데이터는 파일 내부에 포함되어 있습니다. Leaflet과 배경지도 타일은 외부 CDN·타일 서버를 사용합니다.

### 분리형 파일 로컬 실행

```bash
cd yuseong-heatwave-map
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/yuseong-heatwave-map-index.html`을 엽니다.

## GitHub Pages 게시

1. 폴더의 내용 전체를 저장소 루트에 업로드합니다.
2. 첫 화면 파일로 사용하려면 `yuseong-heatwave-map-index.html`을 `index.html`로 복사하거나 이름을 변경합니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/root`를 선택합니다.
4. 게시 주소에서 지도 타일, 탭, 검색, 팝업과 정책 레이어를 확인합니다.

## 이번 수정본의 주요 동작

- 통합지도에서 행정동을 선택하면 선택 행정동은 원래 색상으로 유지하고, 나머지 12개 행정동은 반투명 회색 마스크로 덮어 공간 범위를 명확히 구분합니다. 전체를 선택하면 행정동 마스크가 해제됩니다.
- 통합지도에서 선택한 격자를 유지한 채 표시 지표를 바꾸면 우측 상세정보가 새 지표에 맞춰 자동 갱신됩니다.
- 취약지역 순위에서 행을 선택하면 선택한 순위 유형과 동일한 통합지도 지표로 이동합니다.
- 정책 유형을 변경하면 기존 후보 팝업과 우측 상세정보가 초기화됩니다.
- 스마트복합쉼터는 공원명 기준 11개 지점으로 표시하며, 속들어린이공원 4개 격자는 하나의 복합 후보로 통합합니다. 후보 선택 시 기후노출도, 활동 취약점수·백분위·등급, 거주인구와 핵심 설치 판단을 제공합니다.
- 그늘막쉼터 10개 후보는 첨부 PPT의 지점명, 폭염·활동 지표와 후보지 특징을 상세 패널에 표시합니다.
- 무차양 정류장은 정류장명으로 표시하고, 원자료에서 확인된 정류장은 월평균 승차·하차·환승 인원을 함께 제공합니다.
- 쿨링포그는 주요 입지명과 평균·최고 LST, 시간활동·성연령 점수, 300m 내 거주 4·5등급 인구, 보행 노출 위험 백분위를 제공합니다.
- 살수차 지도는 드롭다운 체크목록에서 도로 고온 1~5등급과 우선 운영구간을 각각 켜고 끌 수 있습니다.
- 도로 링크는 기존보다 약 2배 굵게 표시하고 클릭 허용범위를 확대했습니다. 선택하면 LINK ID, 도로명, 차로 수, 제한속도, 길이, LST, 상대고온도, 날짜별 백분위, 33℃ 이상 비율, 유효 촬영일, 도로면 점유율과 고온점수를 우측 패널에서 확인할 수 있습니다.
- 고해상도 지표면온도 지도는 OpenStreetMap을 사용하며, 전용 버튼으로 LST 레이어를 켜고 끌 수 있습니다. 지도 이동·확대 시 Leaflet 레이어 좌표로 캔버스를 재배치해 경계와 정렬합니다.

## 데이터 공개 원칙

- `Welfare_score_100_final`과 사회경제적 취약계층 세부 점수·인원은 HTML과 GeoJSON에 포함하지 않았습니다.
- 거주 기반 민감도는 최종 종합점수와 공개 가능한 연령별 인구구조 집계값만 제공합니다.
- 연락처, 시설 관리번호, 테이블 ID, 로컬 경로와 과거·중간 산출 필드는 제외했습니다.
- 가로수·녹음 부족도 관련 필드는 최종 공개 분석체계에서 제외했습니다.
- 살수차 도로 링크의 `LINK ID`는 이번 요청에 따라 도로온도 상세정보 식별용으로 공개합니다.

## 패키지 재생성

현재 분리 데이터와 자산에서 단독 HTML과 ZIP을 다시 생성합니다.

```bash
python build_site.py \
  --package-dir . \
  --road-html ../yuseong_road_temperature_map_rebalanced_priority10_v4.html \
  --zip-path ../yuseong-heatwave-map.zip
```

`--road-html`은 생략할 수 있습니다. 지정하면 원본 도로온도 HTML에서 9,557개 링크와 상세 필드를 다시 추출합니다. 최초 GPKG·XLSX·Parquet 변환 과정은 `legacy_build_base.py`와 필드 매핑표를 참고합니다.
